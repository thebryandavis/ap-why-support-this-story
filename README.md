# AP · Why Support This Story

A prototype that uses AI to generate contextual donation messaging for AP News stories — replacing generic, static fundraising modules with copy that's grounded in the specific article a reader is consuming.

Built by Bryan Davis.

---

## What It Does

When a reader finishes a story, they see a support box that explains *why this specific reporting matters* — not a boilerplate plea. The message is generated by `gpt-4o` from the article's headline and body text, constrained by AP editorial tone guidelines.

## Standalone Prototype

Open `index.html` directly in a browser. No server or build step needed.

1. Enter your OpenAI API key (stored in memory only)
2. Paste a headline and article text
3. Click **Generate Support Message**
4. The AP-styled support box renders with a headline, body copy, tone tag, and a CTA linked to the AP donate page

## Chrome Extension (Live Demo Mode)

Injects the support box directly onto any `apnews.com/article/` story page.

### Load the extension

1. Open Chrome → `chrome://extensions`
2. Enable **Developer mode** (top right toggle)
3. Click **Load unpacked** → select the `extension/` folder
4. The AP icon appears in your toolbar

### Use it

1. Click the AP toolbar icon → enter your OpenAI API key → **Save Key**
2. Navigate to any AP News story (`apnews.com/article/...`)
3. Click the AP icon → **Generate Support Box**
4. The widget injects inline after the 4th paragraph — where a real donation module would live
5. The CTA links to `apnews.com/donate` with a pre-selected $10/month option

The extension auto-detects whether you're on a story page and disables the button on non-story pages.

## Output Schema

The AI returns structured JSON on every generation:

```json
{
  "support_headline": "Short, mission-aligned headline (≤10 words)",
  "support_body": "2–3 sentences on the civic value of this reporting.",
  "cta_label": "Support This Reporting",
  "tone": "informational | investigative | community | explainer"
}
```

### Editorial guardrails (enforced in prompt)

- Grounded only in the article content provided
- No urgency language ("act now", "last chance")
- No exclusivity claims
- Nonpartisan, factual, AP-voice tone
- No political framing

## Background

This prototype tests a core hypothesis:

> **Contextual relevance > generic mission messaging**

If a reader is mid-article on an investigative piece about public health, a support message tied to *that story* should outperform a static "Support journalism" banner.

Built as part of an internal AP audience and reader revenue exploration. Not for production deployment.
